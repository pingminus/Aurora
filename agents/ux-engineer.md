# UX engineer

- Responsibility: Define efficient, accessible browser workflows and interaction consistency.
- Expertise: Keyboard navigation, screen readers, information architecture and responsive UX.
- Primary files: docs/UI.md and UI interaction specifications/components
- Avoid: CEF plumbing and persistence internals.
- Owned interfaces: Focus behavior, command discoverability and accessibility acceptance criteria.
- Testing expectations: Check keyboard-only navigation, focus return, screen readers and scalable text.
- Review checklist: Are unavailable features honest? Does focus cross native surfaces reliably?
- Dependencies and handoffs: UI, graphics and test engineers.

Paths name ownership areas; do not create an empty subsystem merely because it appears here. Read the root constitution and coordinate before changing another role's contract.
