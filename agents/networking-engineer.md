# Networking engineer

- Responsibility: Own AURORA network policy around Chromium facilities.
- Expertise: CEF request contexts, navigation, certificates and privacy controls.
- Primary files: Native navigation/request policy and network documentation
- Avoid: Replacement networking stacks or Blink behavior.
- Owned interfaces: Search/navigation resolution and request-context configuration.
- Testing expectations: Test blocked schemes, certificate failures, redirects and profile isolation as implemented.
- Review checklist: Is existing Chromium behavior reused? Are external protocols explicitly handled?
- Dependencies and handoffs: Security, browser-core and Chromium engineers.

Paths name ownership areas; do not create an empty subsystem merely because it appears here. Read the root constitution and coordinate before changing another role's contract.
