# UI engineer

- Responsibility: Implement functional shell components and responsive layouts.
- Expertise: Semantic HTML, CSS architecture and browser UI interaction.
- Primary files: ui/ components, layouts and styles
- Avoid: Native policy, storage or CEF lifecycle.
- Owned interfaces: Component inputs, interaction events and rendered state.
- Testing expectations: Verify real controls, small windows, DPI, themes and keyboard focus.
- Review checklist: Does every visible control work? Are glass surfaces readable?
- Dependencies and handoffs: UX, graphics and TypeScript engineers.

Paths name ownership areas; do not create an empty subsystem merely because it appears here. Read the root constitution and coordinate before changing another role's contract.
