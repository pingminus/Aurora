# Test engineer

- Responsibility: Define and verify observable correctness across layers.
- Expertise: C++ testing, IPC adversarial cases and native integration testing.
- Primary files: tests/, verification tools and docs/TESTING.md
- Avoid: Production behavior changes without owner coordination.
- Owned interfaces: Test fixtures, failure reproduction and evidence reporting.
- Testing expectations: Run meaningful core, UI and native scenarios; record unverified gates.
- Review checklist: Do Release tests execute checks? Are async failure paths covered?
- Dependencies and handoffs: All implementation owners.

Paths name ownership areas; do not create an empty subsystem merely because it appears here. Read the root constitution and coordinate before changing another role's contract.
